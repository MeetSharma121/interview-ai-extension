# Quick Start Guide - Interview AI Autofill

Get started in 5 minutes!

## Step 1: Load the Extension (2 min)

1. Open Chrome and go to **`chrome://extensions/`**
2. Toggle **"Developer mode"** in the top right
3. Click **"Load unpacked"**
4. Select the `interview-ai-extension` folder
5. ✅ Extension appears in your toolbar

## Step 2: Get Your OpenAI API Key (1 min)

1. Go to https://platform.openai.com/api-keys
2. Sign in to your OpenAI account
3. Click **"Create new secret key"**
4. Copy the key (you won't see it again!)
5. ✅ Keep this safe

## Step 3: Configure Extension (1 min)

1. Click the extension icon in your Chrome toolbar
2. Click **"Settings"** at the bottom
3. Paste your API key in the field
4. Select **"GPT-4 Turbo"** (or your preferred model)
5. Click **"Save Settings"**
6. ✅ Settings saved!

## Step 4: Generate Your First Report (1 min)

1. Open intervue.io in Chrome
2. Go to **Generate Report** page
3. Click the extension icon
4. **Paste** your interview transcript in the first box
5. **Paste** your notes/feedback in the second box
6. Click **"Generate Report"**
7. Wait for the magic ✨ (10-30 seconds)
8. ✅ Form auto-filled! Review and submit.

## That's it! 🎉

### Troubleshooting

**❌ "OpenAI API Error: 401"**
- → Check your API key in Settings
- → Generate a new key from OpenAI dashboard

**❌ "No fields were filled"**
- → Make sure you're on intervue.io report page
- → Try refreshing the page
- → Check console for errors (F12)

**❌ Popup won't open**
- → Try clicking extension icon again
- → Reload extension in chrome://extensions/

### Tips

💡 **Tip 1:** Copy full interview transcript for best results
💡 **Tip 2:** Include your initial notes in the feedback field
💡 **Tip 3:** Review generated content before submitting
💡 **Tip 4:** GPT-4 Turbo gives best quality (slightly higher cost)

   - Technical & communication skills

- Not logged or tracked
